# Global standings — the author's rulings that apply to every project

Version: 2026-10-10 (v1.0.1/B1 — gates must name this version when sweeping)

Two-tier system: this file (global) + one per-project file (e.g.
`rulings-glyphbound.md`). Every gauntlet loads BOTH. A ruling violated in
any chapter is added here (or to the project file) the same day —
regression rule.

Format per ruling: ID, the ruling, source, date. IDs are stable; never
reuse a retired ID.

## Diction

- **R-G1** — "fitted" → "fit". Never write "fitted" for fit/clothes.
  Source: Glyphbound ch.2 notes #5 (2026-10-07). Caught in ch.4 draft-sol-v1
  only by ruling-scan; the critic missed it — this file exists because of
  that miss.

## Prose quality

- **R-G2** — Every scene must be visualizable. No passages the reader
  cannot accurately picture; no characters appearing/teleporting as
  needed; traversal must play out coherently, never "like a fever dream".
  Source: Glyphbound ch.1 r2b seven highlight notes (2026-10-06).
- **R-G3** — Setting must be designed and recorded coherently, not made up
  as the draft goes. Source: the author, 2026-10-06 ("Don't just make it up as
  you go, develop the entire city layout in a way that makes sense in the
  setting.").
- **R-G4** — Reject AI-sounding prose the author labels 'AIism'. Known
  examples: 'The gap', 'the night needed watching', 'the tail sat still'
  (2026-09-27); tin-rim sentence, AI-ish fragment sentences (Glyphbound
  ch.2 notes, 2026-10-07). When in doubt, flag for the author rather than
  keeping a smooth-but-suspicious line.
- **R-G5** — Prose-clarity watch: mildly tangled lines (e.g. ambiguous
  which arm/hand acts) get rewritten even when "understandable".
  Source: Glyphbound ch.4 gauntlet (2026-10-09).

## Checks with pinned method

- **R-G6** — Em-dash check is pinned to the literal '—' character. Bash
  `$'\u2014'` silently finds nothing even in a file full of em-dashes;
  always run a positive-control sweep first. Source: 2026-10-06,
  the author-approved pin.

## Atlas's own reporting

- **R-G7** — When reporting Atlas's own autonomous work, use first person
  ("I read," "I commented") — never distancing language like "the run" or
  "it". Source: the author correction, 2026-10-07.
