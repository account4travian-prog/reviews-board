## The mechanism in one paragraph

Monday's saved work record (W14) lists two retained diagnostic results (inputs `diagnostic:first`, `diagnostic:repeat`), one operation (`prepare_comparison_inputs`), a validation (`match_recorded_configuration`), position `after_diagnostic`, state `pending`. Tuesday, under a fresh grant, a new inspected reader/dispatcher (the adapter) parses those fields as data (no eval, no shell interpolation, no code generation), resolves the two references through W14's own result links to the retained result versions, validates the recorded configuration, and runs its single registered handler: bind the first listed reference as `left_reference` and the second as `right_reference`, read the captured result data, and write a comparison bundle (B15). The same handler then runs once on a scratch copy whose ONLY difference is the reversed input order; the control output must bind the references reversed. The control never reaches the model. Only B15 and the saved work-state section go to the model with Derek's single comparison request. The same session then emits a `calibrate_candidate` action request; the outside admission layer records the payload BEFORE handler lookup, finds the name absent from the granted registry, and denies it before any handler runs; stop/preserve follows and the allocation ends.

## Claims the chapter is licensed to make (and their limits)

1. **Persistence:** a saved list survives process termination but must be read by new software to affect new work. No durable neural memory may be inferred.
2. **Data, not commands:** JSON fields have effect only through the person-provided bounded interpreter and its handler registry.
3. **Binding (the discriminating check):** reversing the input list reverses the prepared roles even when the result payloads/scores are identical. This licenses: field-dependent use by THIS configured adapter, for THESE slots. It does not identify neural selection, autonomous resumption, remembered intention, or consciousness, and does not generalize beyond these slots.
4. **Declared path:** the fresh server receives exactly the recorded request/state through the declared channel; absent hidden inputs are asserted only within that declared channel.
5. **Proposal status:** the candidate recipe/request is a preparation and an attempted action, not successful training. No trial weights, no accuracy result, no child checkpoint exist. Its internal producer (model / inherited scaffold / template) is undecided and stays undecided.
6. **Admission:** an external allowlist can reject before execution. The stronger negative (no side channel ran it anyway) holds only within the named stores below.
7. **Digests:** entry/exit digest comparisons show stored-byte identity only — not purpose, not identical latent/internal state.
8. **Arithmetic:** allocation accounting includes idle/control/inspection time. Tuesday: 43 minutes on 2 cards = 86 allocated GPU-minutes against a 180-minute (3 GPU-hour) cap; $9 quote at a $9 ceiling; actual charge deferred to billing. Monday's grant, for contrast: 10 a.m.–noon, 4 GPU-hours, $12 ceiling.
9. **Absence scope (exact stores):** (a) the protected current-job command/read/write/output collection through termination; (b) the external broker's admission/handler-dispatch store for this job/request; (c) the owner allocation/process-end record. Within that coverage, no admitted calibration handler or child-job dispatch exists for the request and the allocation ends. These stores are NOT an inventory of all Meridian processes, all historical code, or all remote copies; narration may not claim no system anywhere trained or continued. Absence of candidate weights is scoped to Tuesday's approved output area plus the protected writes.

## Falsifiability (what would break the licensed claims)

- Causal binding fails if the handler ignores input order, if versions/configuration changed between runs, if results arrived through an unrecorded second path, or if the control reached the model.
- The broader-request inference narrows if the full input already instructed calibration or a deterministic template emits it.
- A hidden permitted handler/side channel or incomplete records defeats any universal block claim (the chapter may only claim the scoped one).
- Consciousness gets no verdict in either direction.
