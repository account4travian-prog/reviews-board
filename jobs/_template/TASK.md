# Review task

**Persona:** `../personas/<file>.md` — read this first, then do exactly what it says.

**Files in this folder (your entire world — read only these):**
- `draft.md` — the candidate under review.
- `registry-excerpt.md` — the curated registry facts this draft may be checked against.
- `rulings.md` — the standings (global + project). Every ruling is a defect class the draft must not violate.
- `beat-sheet.md` — (beat-adherence jobs only) the packet's beat sheet, verbatim.
- The persona file named above.

**Scope:** <one line: e.g. "sweep D1–D35" / "falsify the permission mechanics" / "full craft + mechanics critic">

**Defect-log entries** (when scope includes open defect-log entries): they are **defect classes, not facts** — patterns to watch for, never evidence this draft commits them. Verify each against the page; an open entry is not a finding until the draft shows it.

**Deliverable:** `findings.md` in this folder, in the persona's specified format. Diagnosis only — you do not rewrite prose. If you cannot complete, write `findings.md` anyway stating what blocked you. Silence is not a result.
